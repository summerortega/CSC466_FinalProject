## Research Questions

This project investigates the logic behind dog breed popularity in the United States using AKC breed traits, breed groups, and popularity rankings.

1. Can dog breed traits predict whether a breed is highly popular in the United States?
   - Model approach: Random Forest

2. Do trait-based groups of dog breeds differ in popularity, and how do those groups compare to AKC breed groups?
   - Model approach: Clustering
